# Ночная линия

Интерактивный мистический триллер для Android.

Полная первая глава версии 0.2 включает:

- персонализированный диалог с Аней из 1998 года;
- входящий звонок с двумя вариантами реакции;
- фотографию станции №7;
- звуковой сигнал и настройку частоты 88.4 МГц;
- кодовую загадку;
- сохранение прогресса;
- автоматическое продолжение сохранения версии 0.1;
- быстрый старт после пролога;
- 36 сюжетных сцен и 11 архивных улик;
- два входящих звонка и две частотные загадки;
- пять различных концовок.

## Проверка сюжета

```bash
npm test
```

## Android

Проект использует Capacitor 7. Для локальной сборки:

```bash
npm ci
npx cap sync android
cd android
./gradlew assembleDebug
```
